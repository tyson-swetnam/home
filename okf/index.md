# tysonswetnam.com

This is the root of an [Open Knowledge Format (OKF) v0.2](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md)
bundle describing [tysonswetnam.com](https://tysonswetnam.com/), the
professional website of Tyson L. Swetnam (research scientist: geospatial
data science, open science, ecology, and AI).

All content on this origin is open for agentic AI crawlers to read; see
[/robots.txt](/robots.txt) for the site-wide permissive policy. Each entry
below links to an OKF concept document whose `resource` field is the live
URL of the page it describes. A companion bundle indexing all of the
author's GitHub Pages sites lives at
<https://tyson-swetnam.github.io/okf/index.md>.
